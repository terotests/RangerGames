# chimera (vendored)

The engine crate of [CHIMERA](https://github.com/jamesondh/chimera-vocal-synth)
by Jameson Hodge, a physical-modelling voice synthesizer (a simulated airway:
lungs, vocal folds, vocal tract, lips, nose). MIT licensed, see `LICENSE`.

Copied unchanged from `crates/chimera/src` at commit `092b16c` (2026-11-08),
without its tests and golden data. Keep it unchanged so it can be updated by
copying again; Finnish lives in `crates/rg_voice`.
